# v2.16.0 - Foundation & Admin UX Refresh

**Released: November 2026**

## What's new

- **More mixtape formats are on the way** - This release lays the groundwork for expanded mixtape creation and reveal options in upcoming versions.
- **Anonymous submission privacy hardening** - For mixtapes that enable anonymous submissions, submitter identity is now consistently redacted in details views and API responses.
- **Configurable description visibility** - Mixtapes can now disable track descriptions so they stay hidden from detail pages and API payloads.
- **Admin area styling refresh** - Admin pages now use clearer grouped sections and more consistent control styling for faster configuration.

## Notes

- Hidden descriptions are not deleted from stored submissions; visibility is controlled by mixtape settings.
- More detail on upcoming mixtape formats will be announced in a future release.
